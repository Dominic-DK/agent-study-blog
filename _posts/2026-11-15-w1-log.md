# W1 진행 로그

- **한 것**: GitHub 가입, AI와 대화하며 기본 세팅 완료(gh 설치 · 로그인, 사이트 저장소 받기), 「내 목표」 · 자기소개 작성
- **막힌 점**: 처음이라 전체 그림이 아직 안 잡힘
  - 지금 하는 과정이 무엇인지 정확히 모르겠음 (AI가 시키는 것을 수행하는 데 그침)
  - GitHub · Claude Code 같은 도구에 대한 기본 이해가 부족함
  - 어떤 데이터를 수집하고 어떤 규칙을 정해야 할지 감이 안 잡힘
- **다음 할 것**: 0단계 인터뷰로 규칙의 출발점 만들기
  - 0단계 인터뷰 날짜 잡고 진행
  - 저장소 초대 받고 커밋한 내용 올리기
  - W2 진행 (`sources.md` 작성 + 기존 스크랩을 `raw/`로 모으기)
  - 진행 과정을 이해하기 위해 GitHub · Claude Code 같은 도구 공부
  - 어떤 정보를 어떤 방식으로 AI를 활용해 수집할지 고민
