### 공유된 내용

- **기간 · 미팅**: 6주 (11/10 ~ 12/20). 온라인 미팅은 오늘 포함 3회 (킥오프 · 중간 · 마무리)
- **쓰는 곳**: 디스코드 · [사이트](https://dominic-dk.github.io/agent-study-blog/) · [질문 · 할 일 이슈](https://github.com/Dominic-DK/agent-study/issues). 이슈 시스템을 기본으로 깔아두고, Git 기초도 겁먹지 않게 자료로 같이 드림
- **진행 방식**: 매주 월요일 도미닉이 보조자료 + 과제 공유 → AI에게 맡겨서 처리 → 결과도 AI가 GitHub에 정리. 사이트나 GitHub을 직접 열지 않아도 **CLI에서 지시 · 처리 · 확인**. 루프가 완성되면 별도 에이전트로 만들어 상시 프로세스로 켜두기
- **원칙**: 20달러 플랜 가정 → LLM은 필요한 단계에만 국소적으로. 대신 「AI OS」라고 부를 만큼 업무를 AI 기반으로 처리 · 연동하는 법을 배움 → [20달러 플랜에서 쓰는 원칙](../guides/usage-principles.md)
  - 20달러 플랜에서도 Opus 5.5로 매일 조금씩 만드는 건 가능 (5시간 한도는 빠듯)
- **에이전트 4요소 자료**: [하네스 커리큘럼](https://harness-curriculum.vercel.app/) — 컴공 개론처럼 선수과목 그래프(LLM 작동 원리 → 에이전트란 무엇인가 → …)를 따라가는 자료. 단원마다 1단계 차근차근(배경지식 없이) · 2단계 원리 · 이해 · 3단계 연구 수준. 이번 주부터 계속 참고
  - 요지: 에이전트라는 말에 겁먹지 말 것. 결국 반복되는 일을 하는 도구이고, **어떤 툴을 쥐여주나 · 무엇을 관리해줘야 하나 · 어떻게 계속 돌아가게 하나**를 보면 됨
- **목표 잡는 법**: 각자 개인 프로젝트 페이지 맨 아래에 목표를 적으면, 그걸 기준으로 최종 모습 → 단계별로 먼저 도달할 것 → 지금 내 수준을 같이 잡음

### 동균 — 개발 워크플로 · 국부펀드

- 개발 워크플로 = 이슈 발생 → 전달 → 파악 · 개선 → 테스트 → 버전 · 배포. 코딩 자체는 AI가 이미 잘하니, **사람이 하던 일을 낱낱이 풀어보는 게 먼저**: 요청 받는 창구 · 재현 환경 · 개선 · 확인 · PR이나 머지
- 순서: 수동으로 해보기 → 반자동(코딩만 맡기기) → AI 기반으로 처리
- 회사엔 이슈 시스템이 없음 → **요청을 기록하는 창구부터 직접 만들기** (개인 GitHub Issues · Linear 같은 도구 · 필요하면 직접 만들기). Git · 이슈 관리는 이미 익숙함
- 연결만 해두면 매번 사람이 Claude를 켜서 맡겨야 함 → **트리거로 에이전트 깨우기**: 이슈 웹훅을 받는 로컬 서버 · 메일을 반복 확인하는 체커 · 이슈 시스템을 주기적으로 확인(폴링)
- 그다음은 멀티 에이전트, 그리고 권한 · 도구를 오히려 제한해야 하는 단계 (나중에)
- **국부펀드(B)**: 아직 그림이 덜 잡힘 → 도미닉 추가 질문을 받아 이번 주 중 계획 완성

### 우주 — 트렌드 → 인사이트

- 우주 목표: 마케팅 영역에서 AI 에이전트를 쓸 수 있는 범위를 찾고 자동화하기. 특히 **시장 조사 → 인사이트 도출** 과정을 AI로 효율적으로
- 좋은 주제지만 어려운 주제: LLM은 자료가 모일수록 비슷한 쪽으로 뭉치기 쉬워서(확률 분포), 사람의 번뜩이는 아이디어는 잘 안 나옴. 도미닉도 쇼츠 자동화의 「편집장 에이전트」에서 겪는 중 — 리서치 · 수집은 잘하지만 흩어진 정보로 번뜩이는 주제를 뽑는 건 어려움
- 순서: ① 내 트렌드 감각이 어느 정도인지 ② 그 규칙을 말로 설명할 수 있는지 ③ AI에 똑같이 시켰을 때 비슷한 결과가 나오는지 ④ 어디까지 자동화되는지
- 모은 자료를 사람이 다 보기는 너무 힘듦 → 데이터를 분류해 **시그널을 뽑는 여러 기법**을 적용해보고, 티핑포인트가 어디서 오는지 · 인사이트가 나오는지 시험
- 마지막에 내 규칙이 먹히는지 **과거 데이터로 백테스트**: 수많은 키워드 · 트렌드 중에서 적절한 시점에 찾아내고 **이유까지** 찾는지
