# 🎙 마무리 발표 · 회고 — W6 (12/14 ~ 12/20 중, 중간 공유 때 확정)

## 목표

결과 공유 · 회고 · 이후 방향 정하기

## 안건 (60~90분)

| 순서 | 안건 | 시간 | 내용 |
|---|---|---|---|
| 1 | 결과 발표 | 각 15~20분 | 문제 → 구조 → 데모 → 효과 → 한계와 다음 단계 |
| 2 | 상호 피드백 | 10분 | 서로의 결과물에서 가져갈 점 |
| 3 | 총평 | 10분 | 도미닉 피드백 · 실무 적용 / 포트폴리오로 정리하는 법 |
| 4 | 회고 (KPT) | 15분 | Keep · Problem · Try |
| 5 | 이후 | 5분 | 단톡 유지 여부 · 후속 모임 |

## 발표 구성 (5장이면 충분)

1. **문제**: 어떤 반복 업무 · 고민이었나
2. **구조**: 입력 → 처리 → 검증 → 사람 확인
3. **데모**
4. **효과**: 전/후 비교 또는 평가 결과
5. **한계와 다음 단계**
