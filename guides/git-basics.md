# 🌱 Git 기초 — 겁먹지 않게

> 명령어는 외우지 않아도 돼요. 이 스터디에서는 **Claude에게 말로 시키고**, 우리는 「지금 무슨 일이 일어나는지」만 알면 됩니다. 10분이면 읽어요.
> Git을 써본 분은 건너뛰고 [AI 하나로 다 하기](ai-os.md)로 가세요.

## Git = 세이브 포인트

- 게임 세이브처럼, 파일 상태를 원하는 순간에 **저장**해두는 도구예요.
- 저장할 때마다 **언제 · 누가 · 무엇을 · 왜** 바꿨는지 기록돼요 → 언제든 예전 상태를 보거나 되돌릴 수 있어요.
- 구글 문서의 「버전 기록」과 비슷한데, **저장 시점과 설명을 내가 정한다**는 점이 달라요.

## GitHub = 세이브 파일을 올려두는 클라우드 + 협업 도구

- 내 컴퓨터의 기록을 GitHub에 올려두면 다른 사람과 같이 쓸 수 있어요.
- **이슈**(할 일 · 질문 게시판), **Pages**(사이트 만들기) 같은 기능도 있어요.
- 우리 스터디 사이트도 GitHub 저장소에 있는 마크다운 파일로 만들어져요.

## 단어 7개만

| 단어 | 뜻 | 비유 |
|---|---|---|
| 저장소 (repository, repo) | 기록이 관리되는 폴더 하나 | 세이브 파일이 있는 게임 하나 |
| 클론 (clone) | GitHub 저장소를 내 컴퓨터로 통째로 받기 | 게임 설치 |
| 커밋 (commit) | 지금 상태를 설명과 함께 저장 | 세이브 + 메모 |
| 푸시 (push) | 내 커밋을 GitHub에 올리기 | 클라우드에 업로드 |
| 풀 (pull) | GitHub의 새 내용을 내 컴퓨터로 받기 | 클라우드에서 동기화 |
| 이슈 (issue) | 할 일 · 질문 하나를 적는 게시글 | 할 일 카드 |
| 마크다운 (`.md`) | `#` 제목, `-` 목록처럼 간단한 기호로 쓰는 글 형식 | 메모장 + 서식 |

브랜치 · PR(풀 리퀘스트)은 지금은 몰라도 돼요. 필요해지면 그때 다룹니다.

## 하루 흐름

```
        GitHub (클라우드)
          ▲          │
     ④ push      ① pull
          │          ▼
  내 컴퓨터:  ② 파일 고치기 → ③ commit (저장 + 메모)
```

1. **pull** — 시작할 때 다른 사람이 바꾼 내용을 받아요
2. 파일을 고쳐요
3. **commit** — 「무엇을 왜 바꿨는지」 한 줄 메모와 함께 저장해요
4. **push** — GitHub에 올려요 → 우리 사이트는 1~2분 뒤 반영되고 디스코드에 알림이 가요

## Claude에게 이렇게 말하면 돼요

| 하고 싶은 것 | Claude에게 | 실제로 실행되는 명령 |
|---|---|---|
| 사이트 원본 받기 | 「스터디 사이트 저장소 받아줘」 | `gh repo clone Dominic-DK/agent-study-blog` |
| 최신 내용 받기 | 「최신 내용 받아줘」 | `git pull` |
| 뭐가 바뀌었나 보기 | 「지금 뭐 바뀌었어? 보여줘」 | `git status` · `git diff` |
| 저장하고 올리기 | 「확인했어. 커밋하고 올려줘」 | `git add` → `git commit -m "…"` → `git push` |
| 기록 보기 | 「최근에 뭐 바뀌었는지 보여줘」 | `git log --oneline` |
| 되돌리기 | 「방금 고친 거 취소해줘」 | `git restore` · `git revert` |

Claude가 명령을 실행하기 전에 「실행해도 될까요?」 하고 물어봐요. 위 표와 비교해보면서 허락하면, 명령어가 저절로 눈에 익어요.

## 실수해도 괜찮아요

커밋한 내용은 기록에 남아서 거의 다 되돌릴 수 있어요. 사이트 페이지마다 맨 아래 **🕘 수정 기록**도 있어요. 조심할 건 두 가지뿐이에요.

1. **기록을 지우는 명령**: `push --force`, `reset --hard` → Claude가 이런 걸 하자고 하면 멈추고 도미닉에게 물어보기
2. **비밀 정보**: 비밀번호 · 토큰 · 실명 · 연락처 · 회사 내부 정보는 커밋하지 않기. 스터디 사이트 저장소는 **공개**라 한 번 올리면 기록에 남아요

## 자주 보는 메시지

| 메시지 | 뜻 | 이렇게 말하기 |
|---|---|---|
| `rejected` · `fetch first` · `non-fast-forward` | GitHub에 내가 아직 안 받은 새 내용이 있음 | 「pull 하고 다시 올려줘」 |
| `CONFLICT` | 나와 다른 사람이 같은 줄을 고침 | 「충돌 난 부분 보여주고 같이 정리해줘」 |
| `Permission denied` · `403` | 저장소 초대를 수락 안 했거나 로그인이 안 됨 | 초대 수락 확인 · `gh auth status` |
| `nothing to commit` | 바뀐 게 없음 | 괜찮아요 |
