# 💸 20달러 플랜에서 쓰는 원칙

> Pro 플랜의 제약은 기능보다 **사용량 한도**입니다. 아래 원칙만 지켜도 두 분 과제는 충분히 돌아갑니다.
> 작업마다 맞는 모델과 비용을 고르는 건 실무 AX에서도 핵심 역량입니다.

1. **LLM은 판단이 필요한 단계에만**: 수집 · 파싱 · 청킹처럼 정해진 처리는 스크립트로, 요약 · 분류 · 분석만 모델에 맡기기. 사용량이 가장 많이 줄어드는 방법입니다.
2. **기본은 Sonnet, 단순 작업은 Haiku**: 상위 모델은 설계가 막힐 때만.
3. **컨텍스트를 작게**: `CLAUDE.md`는 짧게, 작업이 바뀌면 `/clear`, 볼 파일은 직접 지정 (레포 전체를 훑게 하지 않기).
4. **계획 먼저, 실행은 나중에**: 계획 모드로 한 번 합의하고 실행하면 시행착오로 버리는 사용량이 줄어듭니다.
5. **세션은 짧게, 목적 하나로**: 이슈 1건 · 자료 묶음 1개 단위로 끊기.
6. **반복 절차는 스킬로**: 매번 같은 절차는 스킬 · 커스텀 명령으로 만들어 설명을 반복하지 않기.

## ⚠️ 구독 ≠ 서비스 비용

Claude 구독은 **개발 도구(Claude Code)** 비용입니다. 직접 만든 서비스가 모델 · 임베딩을 호출하는 비용(예: 동균님 B의 RAG 서비스)은 별도입니다.

- API 키(쓴 만큼 과금) 또는 로컬 모델(예: Ollama)로 따로 준비
- 공모전 · 대회는 데이터셋이나 API 크레딧을 주는지 먼저 확인
