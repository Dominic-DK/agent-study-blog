## 📈 우주 {#wooju}

### 📖 읽기 (15분)

- **[생각이 쌓이는 길](https://claude.ai/artifact/BJn371Yb5JdAjSngKsRaXb)** — 세컨드 브레인과 LLM wiki의 차이, 메모를 등록할 때 wiki가 바뀌는 과정, 정리한 자료로 나를 돌아보는 방법을 설명합니다.
- 읽은 뒤 일요일 진행 로그에 한 문장을 작성합니다. 「내 메모에서 본 것 · 저장 이유 · 가설 중 가장 부족한 것은 ○○이다. 그 이유는 …」

### 🧰 실무 상황 과제 — 팀 자료실 구축 (1시간) · [#39](https://github.com/Dominic-DK/agent-study/issues/39)

입사 3주 차입니다. 지난주 회의에서 활용한 신호 표를 두고 옆 팀에서 문의가 왔습니다. 「이 신호를 처음 확인한 날이 언제인가요? 반대 의견은 없었나요?」 표 작성자가 휴가 중이어서 아무도 답하지 못했고, 팀장은 담당자가 없어도 확인할 수 있는 자료실을 만들어 달라는 이슈를 등록했습니다.

```
agent-study-blog/resources/w3-pack/wooju/
├── brief.md               ← 업무 지시서
├── page-format.md         ← 자료실 페이지 형식
├── excerpt-format.md      ← 예전 기록 발췌 형식 (실전 2)
└── reflection-format.md   ← 돌아보기 형식 (실전 3)
```

W2의 가상 스크랩 6건(`w2-pack/wooju/raw-sample/`)을 다시 사용합니다. 같은 자료를 표로 정리했을 때와 자료실로 정리했을 때의 차이를 비교해 보세요.

| 단계 | Claude에게 요청할 내용 | 확인할 사항 |
|---|---|---|
| 1. 지시 전달 | 「`@agent-study-blog/resources/w3-pack/wooju/brief.md`를 읽고 이해한 내용을 5줄로 설명해 줘. 작업은 아직 시작하지 마.」 | 의도한 업무와 일치하는가 |
| 2. 질문 | 「시작하기 전에 확인할 사항을 한 번에 하나씩 질문해 줘. 질문이 끝나면 "질문 끝"이라고 알려 줘.」 | W2와 비교해 질문이 어떻게 달라졌는가 |
| 3. 작성 규칙 | 「`@agent-study-blog/resources/w3-pack/wooju/page-format.md`를 참고해 `trend-agent/practice/library/CLAUDE.md`에 작성 규칙 6개를 기재하고 멈춰 줘.」 | 규칙 6개의 뜻을 직접 설명할 수 있는가 |
| 4. 1건 등록 | 「`@agent-study-blog/resources/w2-pack/wooju/raw-sample/01-insta-reel.md`만 등록해 줘. 작성할 페이지를 먼저 알려 주고, 내가 확인하면 작성한 뒤 멈춰 줘.」 | 「저장 이유」가 원문과 일치하는가 |
| 5. 나머지 등록 | 「나머지도 한 건씩 등록하고, 건마다 작성한 페이지와 수정한 페이지를 한 줄로 알려 줘.」 | 기존 페이지도 수정했는가 |
| 6. 질문하기 | 「wiki에 있는 내용만으로 답하고 문장마다 근거 파일을 표기해 줘. ① 들깨 라떼의 최초 확인일은? ② 반대 신호는? ③ 자료실에 없어 답할 수 없는 내용은?」 | 근거 파일에 해당 내용이 있는가 |
| 7. 점검 | 「근거가 없는 문장, 날짜가 없는 자료, 다른 페이지와 연결되지 않은 페이지를 표로 정리해 줘. 수정은 하지 마.」 | 직접 발견한 문제가 표에 포함됐는가 |
| 8. 수정 | 「표의 ○번을 다음과 같이 수정해 줘: …」 | 수정 전후가 어떻게 달라졌는가 |
| 9. 기록 | 「`trend-agent/practice/library/worklog.md`에 지시, 질문, 중간 보고, 수정 사항, 배운 점을 5줄로 기록해 줘.」 | — |

> 💡 4단계에서 「저장 이유」가 원문과 다르면 「저장 이유를 원문 그대로 다시 옮겨 줘」라고 요청하세요. 이후 돌아보기에서 본인의 판단을 확인하려면 원문이 필요합니다.

### 🛠 실전 1 — 내 스크랩을 wiki로 정리 (1시간) · [#40](https://github.com/Dominic-DK/agent-study/issues/40)

W2에서 작성한 `raw/` 메모 5건을 같은 방식으로 정리합니다.

1. 「`@trend-agent/practice/library/CLAUDE.md`를 참고해 `trend-agent/CLAUDE.md`에 내 wiki의 작성 규칙을 기재하자. 항목마다 질문하고 내 답을 반영해 줘.」
   - 연습에서 불편했던 점이 있으면 규칙을 추가하거나 제외합니다.
2. 「`@trend-agent/raw/`에서 메모 한 건을 선택해 wiki에 등록해 줘. 작성할 페이지를 먼저 알려 줘.」 결과를 확인한 뒤 나머지를 등록합니다.
3. 「wiki에 있는 내용만으로, 내가 반복해서 저장한 주제를 알려 줘. 문장마다 근거 파일을 표기해 줘.」
4. 직접 작성한 질문 2개를 추가로 묻고, 답변이 부정확하면 근거 파일과 대조합니다.

### 🔎 실전 2 — 예전 기록 발췌 (1시간) · [#41](https://github.com/Dominic-DK/agent-study/issues/41)

스크랩 5건만으로는 판단 방식을 돌아보기에 자료가 부족합니다. 날짜가 남아 있는 예전 기록(메모, 캡처, 과제 파일, 일기 등)에서 10건 안팎을 발췌합니다.

1. `excerpt-format.md`의 **발췌 기준 4개**를 먼저 확인합니다.
2. 원본에서 직접 검색합니다. [#18](https://github.com/Dominic-DK/agent-study/issues/18)에 정리한 사례 이름이나 당시 자주 사용한 단어를 검색어로 사용합니다.
3. 날짜와 문장을 `trend-agent/raw/me/`에 옮기고, 「현재 생각」을 직접 작성합니다.
4. 「`@trend-agent/raw/me/`의 자료를 작성 규칙에 따라 한 건씩 wiki에 등록해 줘.」

- 관련 기록을 찾지 못한 사례는 「없음」으로 표기합니다.

### 🪞 실전 3 — 돌아보기 (1시간) · [#42](https://github.com/Dominic-DK/agent-study/issues/42)

Claude의 가설을 먼저 읽으면 본인의 판단이 영향을 받을 수 있으므로 **직접 작성한 뒤 비교**합니다.

1. `reflection-format.md`를 `trend-agent/reflection.md`로 복사하고 1번 항목을 직접 작성합니다.
2. 「`@trend-agent/wiki/`에 있는 내용만으로 `@trend-agent/reflection.md` 2번 표의 가설과 근거 파일을 작성해 줘. 관점별로 2개 이하로 작성하고, 근거가 1건이면 "근거 1건"으로 표기해 줘. 판정은 비워 둬.」
3. 항목마다 맞음 · 아님 · 수정으로 판정합니다. 「아님」이 하나도 없으면 근거 파일을 다시 확인합니다.
4. 3번과 4번 항목을 직접 작성합니다. 4번은 W2 진행 로그에서 막혔다고 한 「믿는 정도」와 「왜 저장했나」의 기준입니다.

- ✅ **확인**: 내가 관심을 두는 것, 확신할 때 확인하는 것, 놓치는 것을 근거 파일과 함께 설명할 수 있다.

## 🙋 진행이 어려울 때

- 「저장 이유」가 바뀌었을 때: 「저장 이유를 원문 그대로 다시 옮겨 줘. 앞으로도 수정하지 마.」
- 페이지가 지나치게 많을 때: 「메모 한 건당 새 페이지는 3개 이하로 작성하고 비슷한 페이지는 통합해 줘.」
- 답변의 근거가 없을 때: 「wiki에 있는 내용만으로 답하고, 없으면 없다고 알려 줘.」
- 현재 작업을 모를 때: 「등록, 질문, 반영, 점검 중 어떤 작업을 하고 있는지 알려 줘.」
- 해결되지 않으면 #❓질문에 화면 캡처와 함께 남겨 주세요. Q&A 전에도 답변합니다.
