# 📝 W2 과제 — 일 맡기고, 중간에 확인하고, 결과 받기

> 🚧 **확정 전 초안입니다.** 메뉴에는 보이지 않고 이 주소로만 열려요. 내용은 바뀔 수 있습니다.

| 항목 | 내용 |
|---|---|
| 기간 | (공개일) ~ 11/22 (일) |
| 걸리는 시간 | 읽기 15분 + 연습 1시간 + 실전 1~2시간 |
| 사용량 | 적게 씀 (Sonnet으로 충분) |
| 제출 | 따로 없어요. 이슈 댓글과 일요일 진행 로그로 |

> 이번 주 목표는 하나예요. **Claude에게 일을 맡길 때, 회사에서 팀장이 신입에게 일을 주는 순서를 그대로 밟아보기.** 지시 → 되묻기 → 자료 확인 → 수행 → 중간 보고 → 결과 → 검토. W1에서는 Claude가 하자는 대로 따라갔다면, 이번 주는 내가 팀장이에요.

## 📖 읽기 (15분)

- **[일이 흘러가는 길](https://claude.ai/artifact/GLmHeXPL5Rhmf8xPN79xPs)** — 회사에서 일이 오가는 7단계, 이슈 시스템이 생기면 달라지는 것, 그게 우리 스터디와 Claude Code에서 어떻게 대응되는지
- 읽고 나서 한 줄: 「7단계 중에 지금 내가 제일 약한 단계는 ○○이다. 왜냐하면 …」 → 일요일 진행 로그에

## 🧰 연습 — 가상 자료로 한 바퀴 (1시간)

연습용 꾸러미가 사이트 저장소에 들어 있어요. 내용은 전부 **지어낸 가상 자료**라서 틀려도 괜찮습니다.

```
agent-study-blog/resources/w2-pack/
├── brief.md              ← 업무 지시서 (팀장이 주는 이슈)
├── raw-sample/           ← 스크랩 메모 6개 (가상)
├── sources-example.md    ← 결과물 형식 예시
└── report-format.md      ← 중간 보고 · 결과 보고 양식
```

**준비**: `study/` 폴더에서 Claude를 열고 → 「사이트 최신 내용 받아줘」 → 「trend-agent/practice 폴더 만들어줘」

아래 순서대로 말해보세요. 왼쪽이 회사에서의 단계, 가운데가 Claude에게 하는 말이에요. `@`는 「이 파일을 봐라」는 대상 지정입니다.

| 단계 | Claude에게 (프롬프트 + 대상) | 확인할 것 |
|---|---|---|
| 1. 지시 전달 | 「`@agent-study-blog/resources/w2-pack/brief.md` 읽고, 네가 이해한 내용을 5줄로 다시 말해줘. 아직 작업은 시작하지 마.」 | 내가 생각한 일과 같은가 |
| 2. 되묻기 | 「시작하기 전에 나한테 확인할 것을 한 번에 하나씩 물어봐. 다 물어봤으면 "질문 끝"이라고 해줘.」 | 어떤 질문이 나오는지 적어두기 |
| 3. 자료 확인 | 「`@agent-study-blog/resources/w2-pack/raw-sample/` 안의 파일을 하나에 한 줄씩 정리해줘. 정보가 빠진 파일이 있으면 알려줘.」 | 빠진 정보를 찾아내는가 |
| 4. 계획 | 「어떤 순서로 할지 3~5단계로 보여줘. 내가 OK 하면 시작해.」 | 순서가 납득되는가 |
| 5. 수행 + 중간 보고 | 「1번 파일만 먼저 처리해서 표에 넣고 멈춰. `@agent-study-blog/resources/w2-pack/report-format.md`의 중간 보고 형식으로 알려줘.」 | 첫 줄이 형식에 맞는가 |
| 6. 이어서 | 「좋아, 나머지도 같은 방식으로. 끝나면 결과 보고 형식으로 알려줘.」 | — |
| 7. 검토 | (아래 「검토할 때 볼 것」을 보고) 「`signals.md` ○번 줄은 근거가 약해. 원본을 다시 보고 확신도를 고쳐줘.」 | 고친 뒤 무엇이 달라졌나 |
| 8. 기록 | 「오늘 한 걸 `trend-agent/practice/worklog.md`에 5줄로 남겨줘: 지시 → 질문 → 중간 보고 → 고친 것 → 배운 것.」 | — |

**검토할 때 볼 것** — 결과 파일을 직접 열어서 확인해요.

- [ ] 표의 모든 줄에 근거 파일 이름이 있다
- [ ] 날짜나 출처가 빠진 스크랩을 Claude가 「확인 안 됨」으로 표시했다 (지어내서 채웠다면 다시 시키기)
- [ ] 확신도 「상」을 준 줄은 근거가 두 개 이상이다
- [ ] 반대 신호(안 될 수도 있다는 근거)를 빼먹지 않았다
- [ ] 고쳐달라는 지시를 **한 번 이상** 했다

> 💡 2단계에서 Claude가 물어본 질문은, 처음 지시에 빠져 있던 내용이에요. 다음 지시서에 그걸 미리 적으면 지시가 좋아집니다.

## 📈 우주 — 실전: 내 자료로 한 바퀴 (1~2시간)

이번에는 **지시서를 직접 씁니다.** 연습 꾸러미의 `brief.md`를 본보기로 쓰세요.

| 할 일 | 이슈 |
|---|---|
| 내 소스 목록 `sources.md` | (이슈 번호) |
| 이번 주에 본 것 5개를 `raw/`에 | (이슈 번호) |

**1. 지시서 쓰기** — 「`@agent-study-blog/resources/w2-pack/brief.md`와 같은 형식으로, "내가 자주 보는 곳을 sources.md로 정리하는 일"의 지시서를 같이 쓰자. 칸마다 나한테 물어보고, 내 답으로 `trend-agent/brief-sources.md`를 만들어줘.」

**2. 소스 목록** — 「`@trend-agent/brief-sources.md` 대로 진행해. 인터뷰어처럼 한 번에 하나씩 물어보고, 3곳을 채우면 멈춰서 중간 보고해줘.」
- 「내 목표」에 적은 곳(구글 검색 · 캐릿 · 오픈서베이 · 데이터랩 · 인스타 · 유튜브)에서 시작
- 칸: 이름 · 종류 · 여기서 뭘 보나 · 얼마나 자주 · 믿는 정도 · 주소

**3. 스크랩 5개** — 이번 주에 실제로 본 것을 하나에 메모 하나씩. 「방금 본 걸 `trend-agent/raw/`에 메모로 남기자. `@agent-study-blog/resources/w2-pack/raw-sample/01-insta-reel.md`와 같은 칸으로. 날짜 · 어디서 · 주소 · 본 것 · 왜 저장했나를 물어봐줘.」
- 모아둔 스크랩이 없어도 괜찮아요. 오늘부터 쌓으면 됩니다
- 「왜 저장했나」 칸이 제일 중요해요. 인터뷰에서 꺼낸 판단 기준이 여기에 쌓입니다

**4. 올리기** — 「이슈 ○번에 결과 한 줄 남겨줘: sources 몇 곳, raw 몇 개.」 (`trend-agent/`는 내 컴퓨터에만 있어요. 사이트에는 올리지 않습니다)
