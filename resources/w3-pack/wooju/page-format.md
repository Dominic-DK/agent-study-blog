# 자료실 형식

## 페이지

```
# 페이지 이름

요약:
최초 확인일: 2026-03-08 (근거: 01-insta-reel.md)

## 본 것
- 2026-03-08 · 확인한 사실 (근거 파일)

## 저장 이유
> 「왜 저장했나」 원문 (근거 파일)

## 가설 (Claude)
- 해석 한 문장 (근거 파일) · 상태: 판정 전

## 반대 신호
- 내용 (근거 파일)

## 관련 페이지
- [페이지 이름](파일.md)
```

## 문장 구분

| 구분 | 작성자 | 수정 기준 |
|---|---|---|
| 본 것 | 원본에 기재된 사실 | 원본과 다를 때만 수정 |
| 저장 이유 | 나 | Claude는 수정하지 않음 |
| 가설 | Claude | 내가 맞음 · 아님 · 수정으로 판정 |

## 목차와 등록 이력

```
index.md
- [페이지 이름](파일.md) — 요약 · 근거 3건

log.md
- 2026-11-25 · 01 등록 → 작성: ○○ / 수정: △△
```

## 작성 규칙 6개 (CLAUDE.md에 기재)

1. `raw/`의 원본은 수정하지 않는다.
2. 「저장 이유」는 원문 그대로 유지한다.
3. 본 것과 가설에는 근거 파일을 표기한다.
4. 확인하지 못한 내용은 「확인 안 됨」으로 표기한다.
5. 새 자료를 등록할 때 수정할 페이지를 먼저 알린다.
6. wiki에 있는 내용만으로 답하고, 없으면 없다고 답한다.
