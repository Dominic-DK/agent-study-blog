# 예전 기록 발췌 형식

날짜가 남아 있는 기록을 사용합니다. 메모, 캡처, 과제 파일, 나에게 보낸 메시지, 일기가 해당합니다.

```
# 제목

- **날짜**: 2025-06-14
- **기록 종류**: 예) 메모장
- **원문 발췌**:
- **현재 생각** (직접 작성):
```

파일 위치: `trend-agent/raw/me/2025-06-14-키워드.md`

## 발췌 기준

1. 원본은 `trend-agent/` 밖에 보관하고, 원본 폴더를 Claude에게 열지 않습니다.
2. 원본을 보관한 프로그램에서 직접 검색하고 선별합니다.
3. 다른 사람의 이름과 관계에 관한 내용은 제외합니다.
4. Claude가 읽은 내용은 서버로 전송되고, 저장소에 등록한 내용은 초대받은 사람이 열람할 수 있습니다. 두 경우 모두 공개해도 되는 문장만 옮깁니다.
