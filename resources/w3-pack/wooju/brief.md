# [업무 지시] 스크랩 6건으로 팀 자료실 구축

> 연습용 지시서입니다. 팀장이 이슈로 등록한 업무라고 가정하고 읽으세요. 자료는 모두 가상입니다.

- **지시한 사람**: 팀장 (이 지시서를 Claude에게 전달하는 나)
- **담당자**: Claude
- **기한**: 당일

## 배경

지난주 신메뉴 회의에서 신호 표를 활용했다. 이후 옆 팀에서 「이 신호를 처음 확인한 날이 언제인가요? 반대 의견은 없었나요?」라고 문의했지만, 표 작성자가 휴가 중이어서 답하지 못했다.

담당자가 없어도 자료의 근거와 경위를 확인할 수 있는 **자료실**이 필요하다.

## 업무 내용

1. 자료실의 작성 규칙을 `CLAUDE.md`에 기재한다.
2. 스크랩 6건을 한 건씩 등록하고, 관련 페이지를 작성하거나 수정한다.
3. 목차(`index.md`)와 등록 이력(`log.md`)을 작성한다.
4. 자료실에 있는 내용만으로 팀장의 질문에 답한다.

## 사용할 자료

- W2 꾸러미의 `raw-sample/` 메모 6건 (인터넷 검색은 하지 않는다)
- `page-format.md` (페이지 형식)

## 결과물

| 파일 | 내용 |
|---|---|
| `trend-agent/practice/library/CLAUDE.md` | 작성 규칙 6개 |
| `trend-agent/practice/library/wiki/` | 현상 · 키워드별 페이지 |
| `trend-agent/practice/library/wiki/index.md` | 목차와 페이지별 한 문장 요약 |
| `trend-agent/practice/library/log.md` | 등록일, 등록한 메모, 변경된 페이지 |

## 완료 조건

- 모든 문장을 **본 것 · 저장 이유 · 가설** 중 하나로 구분한다.
- 본 것과 가설에는 근거 파일을 표기한다.
- 메모의 「왜 저장했나」는 원문 그대로 「저장 이유」에 옮긴다.
- 날짜나 출처가 없으면 「확인 안 됨」으로 표기한다.
- 반대 신호를 해당 페이지에 기록한다.

## 중간 보고

- 시작 전: 이해한 내용을 설명하고 확인할 사항을 질문한다.
- 작성 규칙 기재 후: 작업을 멈추고 내용을 보고한다.
- 첫 번째 메모 등록 후: 작업을 멈추고 작성한 페이지를 보고한다.

## 유의 사항

- 원본 메모를 수정하지 않는다.
- 「저장 이유」를 요약하거나 다듬지 않는다.
- 메모 한 건당 새 페이지는 3개 이하로 작성한다.
