# [이슈 본문 예시] 평가 질문 10개로 검색 기준 점수 재기

본인 저장소에 이슈로 올릴 본문입니다. 파일 경로와 이름은 저장소에 맞게 고치세요.

---

## 배경

검색 설정을 바꿀 때마다 좋아졌는지 나빠졌는지 손으로 확인하고 있다. 질문 10개와 정답 문서를 파일로 두고, 명령 한 줄로 점수를 재고 싶다.

## 요구사항

- 질문 파일에서 질문, 유형(검색형 / 심화형), 정답 문서 목록을 읽는다.
- 질문마다 지금의 검색 함수를 그대로 호출해 상위 10개를 받는다.
- 정답 문서가 몇 위에 나왔는지 계산한다. 정답 문서가 여러 개면 각각 계산한다.
- 질문별 결과 표와 요약(3위 안에 든 질문 수)을 출력한다.
- 결과를 날짜가 들어간 파일로 저장한다.

## 완료 조건

- [ ] 명령 한 줄로 실행된다.
- [ ] 정답 문서가 3위에 있으면 통과, 4위면 실패로 나온다.
- [ ] 정답 문서가 여러 개인 질문은 전부 3위 안일 때만 통과로 나온다.
- [ ] 정답 문서가 비어 있는 질문은 점수에서 빼고 「라벨 없음」으로 표시한다.
- [ ] 결과 파일에 실행 날짜와 검색 설정이 같이 남는다.
- [ ] 순위 계산은 실제 DB 없이 가짜 검색 결과로 테스트된다.

## 확인할 점

- 문서를 무엇으로 구분하나 (파일명 / 문서 ID)
- 같은 문서의 청크가 여러 개 나오면 가장 높은 순위를 쓴다

## 이번 이슈에서 하지 않는 것

- 검색 로직 자체를 고치지 않는다. 재기만 한다.
- 답변 품질은 보지 않는다.
